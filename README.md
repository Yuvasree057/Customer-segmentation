# Customer Segmentation using Machine Learning

Developed by **Yuva Sree**

## About the Project

This is a Streamlit-based Machine Learning application that performs customer segmentation using the K-Means Clustering algorithm.

Users can upload a customer dataset, select features for clustering, choose the number of clusters, and visualize customer segments through interactive charts.

## Features

- Upload CSV files
- View dataset preview
- Generate data summary
- Select clustering features
- Choose number of clusters
- Perform customer segmentation
- Visualize customer groups
- View cluster insights

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Yuvasree557/customer-segmentation.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
streamlit run app.py
```

Sample dataset: `Mall_Customers.csv`
